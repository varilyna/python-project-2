# Telegram-bot погоды 
## описание
Бот создан для того, чтобы быстро узнавать погоду. 
## реализуемый функционал 
Бот по введённому городу способен выдавать подробную информацию о погоде в нём
## архитектура 
Две основные функции: 
- приветсвие с пользователем при запуске бота
- функция, благодаря которой бот предоставляет информацию о погоде
